# AI Tic-Tac-Toe (Python)

This project is a Python-based Tic-Tac-Toe game with a graphical interface built using Tkinter. It features an AI opponent that combines the Minimax algorithm with controlled randomness to create competitive but winnable gameplay.

Rather than always playing optimally, the AI uses varied opening strategies, immediate win/block detection, and occasional imperfect decisions to better simulate human-like play. This approach improves replayability and keeps matches interesting.

The project was developed as a learning exercise to demonstrate AI decision-making, algorithmic thinking, and GUI development in Python. The codebase is structured for clarity and future extension, including potential integration with the DeepSeek API for advanced reasoning or move analysis.

## Features
- Tkinter-based graphical user interface  
- AI opponent using Minimax and heuristics  
- Varied and non-deterministic AI behavior  
- Score tracking across multiple games
